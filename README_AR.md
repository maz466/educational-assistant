# المساعد التعليمي — دليل التشغيل والنشر

## ما الذي يتضمنه المشروع؟
- واجهة عربية متجاوبة للطلاب ولوحة إدارة.
- تسجيل أسماء الزوار والصفوف والأسئلة والإجابات في Supabase.
- رفع PDF واستخراج النص منه وتقسيمه إلى مقاطع للبحث.
- وضع بحث واسترجاع من الملف دون API مدفوع.
- خيار تنزيل نموذج Qwen محلياً عبر WebLLM على الأجهزة التي تدعم WebGPU. التنزيل الأول كبير ويستهلك موارد الجهاز؛ ليس كل هاتف أو متصفح مدعوماً.

## 1) إعداد قاعدة البيانات المجانية
1. أنشئ مشروعاً في https://supabase.com (الخطة المجانية).
2. افتح SQL Editor والصق محتوى `supabase.sql` ثم شغّله.
3. من Authentication > Providers تأكد من تفعيل Email.
4. من Authentication > Users أنشئ مستخدم المدير يدوياً.
5. عطّل التسجيل العام (Signups) من إعدادات Auth حتى لا يستطيع الزوار إنشاء حسابات إدارة.
6. من Project Settings > API انسخ Project URL و anon/public key.

## 2) إعداد الموقع محلياً
1. ثبّت Node.js 20 أو أحدث من https://nodejs.org
2. انسخ `.env.example` إلى ملف اسمه `.env`.
3. ضع رابط Supabase ومفتاح anon في `.env`.
4. افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
npm install
npm run dev
```

5. افتح الرابط المحلي الذي يظهر في الطرفية.

## 3) النشر المجاني على Cloudflare Pages أو Vercel
- ارفع مجلد المشروع إلى مستودع GitHub خاص بك.
- أنشئ مشروعاً جديداً في Cloudflare Pages أو Vercel واربط مستودع GitHub.
- أمر البناء: `npm run build`
- مجلد الإخراج: `dist`
- أضف متغيري البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` في إعدادات المشروع قبل النشر.
- أعد النشر بعد إضافة المتغيرات.

## ملاحظات مهمة قبل الاستخدام الحقيقي
- هذا إصدار تأسيسي. سيُظهر البحث مقاطع PDF ذات صلة، ويمكن تشغيل نموذج محلي على جهاز يدعم WebGPU لمحاولة صياغة الإجابة. لا يوجد اتصال بأي API مدفوع.
- النموذج المحلي قد يتطلب تنزيل مئات الميغابايت أو أكثر، وذاكرة/معالج رسومي مناسبين. إذا لم يعمل، يبقى البحث بالمقاطع متاحاً.
- PDF المصوّر ضوئياً دون طبقة نص لا يمكن استخراج نصه بهذا الإصدار؛ يحتاج OCR.
- سياسات SQL الأساسية تسمح للزوار بإضافة بيانات وعرض مقاطع PDF. صلاحيات المدير تمنح لكل مستخدم Auth مسجل؛ لذلك عطّل التسجيل العام وأنشئ حساب المدير يدوياً. في نشر مؤسسي، يُنصح بتقييد الإدارة أكثر عبر جدول أدوار وسياسات RLS مخصصة.
- لا تضع مفتاح `service_role` في الواجهة أبداً. استخدم anon/public key فقط.
- بيانات الطلاب شخصية؛ أبلغ الطلاب وولي الأمر/الجهة التعليمية عن جمع الأسماء والأسئلة، واجمع الحد الأدنى اللازم واحذف السجلات عند انتهاء الحاجة.
