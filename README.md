# المساعد التعليمي — نسخة أولية

## التشغيل
تحتاج Node.js 20 أو أحدث. من داخل المجلد نفّذ:

```bash
npm install
npm run dev
```

## النشر
اربط مستودع GitHub بمنصة Vercel، اختر Vite، أمر البناء `npm run build` ومجلد الإخراج `dist`.

## ملاحظات مهمة قبل النشر العام
- هذه نسخة تجريبية: تستخرج نص PDF وتبحث عن المقاطع الأقرب بالكلمات؛ ليست نموذج ذكاء اصطناعي توليدي.
- السجلات محفوظة في localStorage على نفس المتصفح فقط، وليست قاعدة بيانات مشتركة بين الطلاب.
- كلمة مرور الإدارة التجريبية `change-this-password` موجودة في `src/main.jsx` وليست وسيلة حماية آمنة. يلزم إعداد مصادقة حقيقية وقاعدة بيانات وصلاحيات قبل استخدام الطلاب.
- لا تدعم ملفات PDF المصورة التي تحتاج OCR.
